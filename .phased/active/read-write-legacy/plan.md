## Objective
The low-level read-write cycle and the transactions behave as GenroPy legacy (decisioni.md, Gruppo 6; roadmap Macro 6): the connection API is the legacy one, with `session(db)` as the unit of work outside a request; `db.execute` returns the cursor; deferred calls live in `currentEnv`; single-record writes take the serialized composite key, write Bag values, assign keys in `sql_insert`; `query(...).update()`/`delete()` write record by record through the triggers; a logical deletion cascades as legacy, without dbo.
