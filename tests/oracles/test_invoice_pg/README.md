# Full legacy invoice-model oracle

Generated by `scripts/capture_legacy_invoice.py` using the real GenroPy model
builder and ORM extractor. No application records or connection credentials.
The portable profile and source hashes are in `manifest.json`. GenroPy is only
needed to regenerate the snapshots, not to run the fixture-consumer tests.

From the core repository, with GenroPy importable in the developer environment:

```sh
python scripts/capture_legacy_invoice.py \
  --genropy-root /path/to/Genropy/genropy \
  --output-dir /tmp/invoice-oracle
```

Review the source/profile changes and snapshot diff before replacing committed
fixtures. Never regenerate expected data from the new Asqueel implementation.
The profile intentionally keeps legacy user_upd=False; the new default must be
an explicit difference, not a reason to overwrite the oracle. These snapshots
do not assert that all legacy expressions or application methods are correct.
